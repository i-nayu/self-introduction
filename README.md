# Portfolio

プロフィール、使用技術、制作物を紹介するポートフォリオサイトです。
ページの閲覧に加えて、ターミナルへのコマンド入力でもサイトを操作できます。

[公開サイトを見る](https://self-introduction-ochre.vercel.app/)

## 主な機能

### ページ構成

| ページ | 内容 |
| --- | --- |
| Home | サイトの入口として、操作できるターミナルと注目の制作物を掲載 |
| Profile | 自己紹介やプロフィール、SNSへのリンクを掲載 |
| Skills | 学習・開発で使用した技術をカテゴリごとに整理し、インターン経験も紹介 |
| Products | 制作物の概要、使用技術、公開サイト・紹介ページ・GitHubへのリンクを掲載 |

### ターミナルによる操作

ホーム画面のターミナルから、ページ移動や外部リンクの表示ができます。

| コマンド | 動作 |
| --- | --- |
| `help` | 使用できるコマンドを表示 |
| `ls` | ページ一覧を表示 |
| `cd about` | Profileへ移動 |
| `cd skills` | Skillsへ移動 |
| `cd products` | Productsへ移動 |
| `open github` | GitHubを開く |
| `open x` | Xを開く |
| `echo <text>` | 入力した文字列を表示 |
| `history` | コマンド履歴を表示 |
| `clear` | 表示をクリア |

左右の矢印キーによるカーソル移動、上下の矢印キーによる履歴参照、
Home／Endキーによる先頭・末尾への移動に対応しています。

### 季節に応じた背景と配色

閲覧時の月に応じて、背景の装飾とサイト全体の配色が変わります。
また、スマートフォンでの表示や、OS・ブラウザの「動きを減らす」設定に対応しています。

## 工夫した点

### ターミナルを実際に操作できるUIとして実装

見た目だけの装飾ではなく、コマンド入力によって各ページや外部リンクへ
移動できるようにしました。通常のナビゲーションも用意し、
コマンドを知らなくても閲覧できる構成にしています。

### 掲載データと表示処理を分離

プロフィール、制作物、スキル、インターン経験のデータを、
画面を描画するコンポーネントと分けて管理しています。

また、制作物を利用するためのURLと、その制作物を紹介しているページのURLを
分けて保持し、それぞれの目的が分かるリンクとして表示しています。

### ブラウザ上の操作まで自動テストで確認

表示範囲の計算や入力処理は単体テストで確認し、
ページ移動やターミナル操作はE2Eテストで確認しています。

特にターミナルでは、長い入力、日本語・絵文字、画面サイズの変更、
文字選択、コピー時の文字列保持を検証しています。
GitHub Actionsでも各チェックを実行し、不具合を検出できるようにしました。

## 使用技術と選定理由

| 技術 | 用途 | 選定理由 |
| --- | --- | --- |
| React | UIの構築 | ナビゲーションや制作物カードなどをコンポーネントとして共通化するため |
| TypeScript | 型定義・型チェック | 掲載データやコマンド処理の入出力を明確にし、変更時の不整合を検出するため |
| Vite | 開発・ビルド | 開発中の変更反映と本番用ビルドを扱いやすくするため |
| React Router | ページ遷移 | 共通レイアウトを維持しながら、URLに応じてページを切り替えるため |
| xterm.js | ターミナル表示 | 文字描画、カーソル、スクロール、選択などの機能を利用するため |
| React Icons | アイコン表示 | アイコンをReactのコンポーネントとして扱い、表示方法を揃えるため |
| Vitest | 単体テスト | 入力処理や表示計算などを、ブラウザ操作から切り離して検証するため |
| Playwright | E2Eテスト | 実際のブラウザで、キー入力・マウス操作・画面サイズ変更を検証するため |
| ESLint | 静的解析 | コードの問題を開発中に検出するため |
| GitHub Actions | CI | プルリクエストごとにテストやビルドを自動実行するため |
| Vercel | ホスティング | GitHubと連携してサイトの公開・更新を行いやすくするため |

## 今後の改善点

- **ターミナルのコマンドの充実**
  - ターミナルで使用できるコマンドを充実させる。
- **ブラウザ・端末ごとの操作確認**
  - Chromium以外のブラウザや、Macのキー操作、スマートフォンでの入力・選択を確認する。
- **制作物の紹介内容を充実**
  - 各制作物の担当範囲、開発上の課題、解決方法、得られた学びを整理して掲載する。
- **アクセシビリティの確認を拡充**
  - キーボード操作、フォーカスの移動、読み上げ時の使いやすさを継続して確認する。
